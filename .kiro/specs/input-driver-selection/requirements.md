# 需求文档

## 简介

本功能允许用户在 UI 界面上选择输入驱动方式，支持 Win32 API 软件模拟和 GhostBox 硬件驱动两种方式。GhostBox 支持键盘和鼠标输入，本次实现将完整迁移 SDK 并实现键盘驱动，同时预留鼠标接口以便未来扩展。

## 术语表

- **输入驱动 (Input_Driver)**: 输入设备驱动，负责模拟键盘/鼠标操作
- **Win32驱动 (Win32_Driver)**: 使用 Windows user32.dll API 的软件模拟驱动
- **GhostBox驱动 (GhostBox_Driver)**: 使用幽灵键鼠硬件设备的硬件级模拟驱动
- **驱动选择器 (Driver_Selector)**: UI 组件，允许用户选择输入驱动类型
- **连接状态 (Connection_Status)**: GhostBox 设备的连接状态
- **SDK目录 (SDK_Directory)**: 存放 GhostBox SDK 文件的项目目录

## 需求

### 需求 1: GhostBox SDK 文件迁移

**用户故事:** 作为开发者，我希望将 GhostBox SDK 必要文件迁移到项目中，以便项目可以独立运行而不依赖外部 SDK 路径。

#### 验收标准

1. 系统应在项目根目录创建 `libs/ghostbox/` 目录用于存放 SDK 文件
2. 系统应将 `gbild.dll` 和 `gbild64.dll` 复制到 `libs/ghostbox/` 目录
3. 系统应在项目文件 (.csproj) 中配置 DLL 文件在编译时自动复制到输出目录
4. 当 GhostBox DLL 文件不存在时，系统应允许程序正常运行但禁用 GhostBox 驱动选项

### 需求 2: 驱动类型选择

**用户故事:** 作为用户，我希望在 UI 界面上选择输入驱动类型，以便根据我的需求选择软件模拟或硬件级输入。

#### 验收标准

1. 设置页面应显示驱动选择下拉框，包含 "Win32 (软件模拟)" 和 "GhostBox (硬件驱动)" 两个选项
2. 当用户选择驱动类型时，系统应将选择保存到配置文件
3. 当应用程序启动时，系统应从配置文件加载之前选择的驱动类型
4. 当配置不存在时，系统应默认使用 "Win32" 驱动

### 需求 3: GhostBox 键盘驱动实现

**用户故事:** 作为用户，我希望使用 GhostBox 硬件驱动进行键盘输入，以便我的输入更难被反作弊系统检测。

#### 验收标准

1. GhostBox键盘驱动应实现 IKeyboardInterface 接口
2. 当选择 GhostBox驱动时，系统应尝试连接 GhostBox 设备
3. 当 GhostBox 设备未连接时，系统应显示错误消息并回退到 Win32 驱动
4. GhostBox键盘驱动应支持 PressKey、ReleaseKey 和 PressAndRelease 操作
5. GhostBox键盘驱动应使用 gbild.dll 原生库进行设备通信

### 需求 4: GhostBox 鼠标驱动接口预留

**用户故事:** 作为开发者，我希望预留 GhostBox 鼠标驱动接口，以便未来可以扩展鼠标功能。

#### 验收标准

1. 系统应创建 IMouseInterface 鼠标接口定义
2. 系统应创建 GhostBoxMouseInterface 类实现鼠标接口
3. GhostBox鼠标驱动应支持移动鼠标、点击鼠标按钮等基本操作
4. 鼠标驱动应与键盘驱动共享同一个 GhostBox 设备连接

### 需求 5: 设备连接状态显示

**用户故事:** 作为用户，我希望看到 GhostBox 设备的连接状态，以便知道硬件驱动是否正常工作。

#### 验收标准

1. 当选择 GhostBox 驱动时，设置页面应显示设备连接状态
2. 连接状态应在设备已连接时显示 "已连接"，未连接时显示 "未连接"
3. 设置页面应提供 "重新连接" 按钮以重试设备连接
4. 当设备连接失败时，系统应显示错误原因

### 需求 6: 驱动运行时切换

**用户故事:** 作为用户，我希望在运行时切换驱动，以便无需重启应用程序即可更改输入方式。

#### 验收标准

1. 当用户更改驱动选择时，系统应立即切换到新驱动
2. 如果引擎正在运行时更改驱动，系统应对后续按键使用新驱动
3. 当切换到 GhostBox 驱动失败时，系统应保持使用当前驱动并通知用户

### 需求 7: 配置持久化

**用户故事:** 作为用户，我希望我的驱动选择被保存，以便每次启动应用程序时不必重新配置。

#### 验收标准

1. 系统应将选择的驱动类型保存到 appsettings.json
2. 当配置文件损坏或缺少驱动设置时，系统应使用默认的 Win32 驱动
