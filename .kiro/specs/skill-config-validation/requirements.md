# 需求文档

## 简介

本功能旨在解决技能配置页面中"技能组"和"覆盖条件Buff"下拉框可以选择未在其他地方配置的选项的问题。当前系统允许用户在技能配置中引用不存在的技能组或Buff，这会导致运行时逻辑无法正确执行。

## 术语表

- **技能配置页面**: 用于配置单个技能各项参数的页面
- **技能组**: 在全局设置中定义的一组相关技能的共享条件配置
- **Buff库**: 在全局设置中定义的所有可检测Buff/Debuff的集合
- **技能卡片控件**: 显示和编辑单个技能配置的UI组件
- **验证系统**: 负责检查配置引用有效性的逻辑模块

## 需求

### 需求1: 技能组引用验证

**用户故事:** 作为用户，我希望系统验证技能组引用，以便我只能选择实际已配置的技能组。

#### 验收标准

1. 当用户打开技能组下拉框时，技能卡片控件应只显示在全局设置中已配置的技能组
2. 当技能引用了不存在的技能组时，技能配置页面应显示视觉警告指示器
3. 当从全局设置中删除技能组时，验证系统应识别所有引用该组的技能
4. 如果用户尝试保存带有无效技能组引用的技能，技能配置页面应显示警告消息

### 需求2: Buff引用验证

**用户故事:** 作为用户，我希望系统验证Buff引用，以便我只能选择Buff库中实际已配置的Buff。

#### 验收标准

1. 当用户打开任何Buff相关下拉框（条件Buff、排除条件Buff、优先级覆盖条件Buff、触发条件Buff）时，技能卡片控件应只显示Buff库中存在的Buff
2. 当技能引用了不存在的Buff时，技能配置页面应显示视觉警告指示器
3. 当从Buff库中删除Buff时，验证系统应识别所有引用该Buff的技能
4. 如果用户尝试保存带有无效Buff引用的技能，技能配置页面应显示警告消息

### 需求3: 禁用手动输入无效值

**用户故事:** 作为用户，我希望下拉控件阻止无效的手动输入，以免我意外输入不存在的引用。

#### 验收标准

1. 技能卡片控件应将所有引用下拉框设置为不可编辑模式（IsEditable=False）
2. 当下拉框设置为不可编辑时，技能卡片控件应提供"清空"选项以移除当前选择
3. 技能卡片控件应保持向后兼容性，以警告样式显示现有的无效引用

### 需求4: 配置一致性检查

**用户故事:** 作为用户，我希望系统检查配置一致性，以便我能识别并修复无效引用。

#### 验收标准

1. 当应用程序加载技能配置时，验证系统应检查所有引用的有效性
2. 当发现无效引用时，技能配置页面应用警告指示器高亮显示受影响的技能
3. 验证系统应提供方法列出当前配置中的所有无效引用
4. 当用户将鼠标悬停在警告指示器上时，技能配置页面应显示解释无效引用的工具提示
